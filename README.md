# dev.to-Frontend-Challenge-Comfort-Food-Edition
CSS Art: Comfort Food Create a work of art using primarily CSS! Let food be your inspiration: a steaming bowl of ramen, a stack of pancakes, a perfectly cut slice of pie, or the dish you grew up eating.

## Submission: Kawaii Onigiri 🍙

A big, bold, kawaii rice ball built with HTML + CSS (`clip-path`, gradients, animations) plus a small sprinkle of vanilla JS for the click interaction — idle bounce, blinking eyes, twinkling sparkles, and a squishy happy-eyes + sparkle-burst reaction on click.

Open `index.html` in a browser to view it. See [`SUBMISSION.md`](./SUBMISSION.md) for the full write-up.
