# dev.to-Frontend-Challenge-Comfort-Food-Edition
CSS Art: Comfort Food Create a work of art using primarily CSS! Let food be your inspiration: a steaming bowl of ramen, a stack of pancakes, a perfectly cut slice of pie, or the dish you grew up eating.

## Submission: Comfort Food Squad 🍙🧋🥟🍲

A dark, neon-lit restaurant scene: a flickering "COMFORT FOOD" sign above a digital menu screen (CRT scanlines, glowing bezel) where four kawaii mascots — Onigiri, Boba Tea, Gyoza, and Hot Pot — double as the menu items, each with a price tag. Below them, a touchscreen self-order kiosk (à la fast-food ordering stations) types out "Can I take your order?" with a pure-CSS typewriter effect, pulses a "TAP TO ORDER" button, and prints a receipt with an order number. Built with HTML + CSS (`clip-path`, gradients, `steps()` animations) sharing one small vanilla-JS click handler for the food characters. Every character bounces on its own and blinks; clicking one gives it happy `^^` eyes and a sparkle burst.

Open `index.html` in a browser to view it. See [`SUBMISSION.md`](./SUBMISSION.md) for the full write-up.
